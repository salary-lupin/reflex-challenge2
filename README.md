# Reaction 10 Challenge 2 🚀

[![Deploy to GitHub Pages](https://github.com/salary-lupin/reflex-challenge2/actions/workflows/deploy.yml/badge.svg)](https://github.com/salary-lupin/reflex-challenge2/actions/workflows/deploy.yml)

두 번째 버전의 순발력 10단계 챌린지 게임입니다.

## 🎮 게임 소개
10가지 다양한 미니게임을 통해 당신의 순발력을 테스트하세요!
각 단계는 제한 시간 내에 정확한 동작을 요구합니다.

## 🛠 기술 스택
- **HTML5 / CSS3 / Vanilla JavaScript**
- **Firebase Realtime Database**: 글로벌 랭킹 시스템
- **GitHub Actions**: 자동 배포 (GitHub Pages)

## 🚀 시작하기
1. 이 저장소를 클론합니다.
2. `config.js` 파일을 생성하고 Firebase 설정을 입력합니다. (템플릿 참고)
3. `index.html`을 브라우저에서 엽니다.
